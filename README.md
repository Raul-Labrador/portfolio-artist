## 📝 Project Overview

This project was developed as part of my advanced training in **Multimedia Design and Visual Communication (DEPIM)**. The main goal was to design and implement an interactive web interface focusing heavily on user experience (UI/UX), visual hierarchy, and clean information architecture.

While it is a frontend-centric project, it demonstrates my ability to organize complex layouts, manage asset optimization, and create intuitive interfaces—skills that are essential when building clear data visualizations and analytical dashboards.

## ⚡ Key Features & UI/UX Principles

- **Visual Hierarchy:** Optimized layout to guide the user's attention efficiently through typography, contrast, and spacing.
- **Interactive Elements:** Developed with Vanilla JavaScript to manipulate the DOM dynamically (smooth animations, interactive menus, or component behaviors).
- **Asset Optimization:** High-quality imagery and graphics optimized for fast web performance and minimal loading times.
- **Clean Architecture:** Standard-compliant HTML5 structural elements and modular CSS3 styling.

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3 (Flexbox / Grid), Vanilla JavaScript.
- **Design & Prototyping:** Adobe Creative Suite (Photoshop / Illustrator).
